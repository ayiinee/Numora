# Contoh Excel V4 DEMO

Pilih tujuan yang sesuai di http://localhost:3000/admin/content/imports. Filter sumber NUMORA, lalu pilih paket DEMO dengan kode pada PAKET_DEMO.json. Unggah file tujuan tersebut; jangan mengubah sheet Paket. Nomor unik lintas sheet. Gambar sengaja kosong dan dapat diisi pada kolom img_* beserta alt_*.

Contoh adalah aritmetika pengujian pipeline, bukan konten akademik/blueprint resmi. Tiga paket baru disiapkan sebagai DRAFT kosong; contoh soal belum dimasukkan ke bank. Untuk konten resmi, buat paket baru dengan sumber dan cakupan yang benar, lalu unduh templatenya.
