## Perbaikan penting terhadap interpretasi awal

### 1. Dua critical Next tidak boleh dibaca sebagai dua eksploitasi yang sudah terbukti

Next yang terpasang adalah **16.3.6**. Advisory Image Optimization RCE mempunyai kondisi Linux berbasis glibc. Jalur `next > sharp` lokal sudah menggunakan **sharp 0.35.5**, memenuhi workaround resmi >=0.35.5. Mesin QA saat ini Windows, dan satu penggunaan next/image yang ditemukan adalah QR dengan `unoptimized`. Kesimpulan: **workaround teramati secara lokal; kondisi eksploitasi tidak dibuktikan**. Build/deployment Linux lain harus memverifikasi artefak yang benar-benar dipakai, bukan mengandalkan instalasi Windows ini. [Advisory maintainer](https://github.com/vercel/next.js/security/advisories/GHSA-2464-fhr4-w9xw).

Critical kedua mensyaratkan App Router dengan Cache Components dan fungsi `use cache` yang mengembalikan beberapa typed array. Pencarian source aplikasi dan next.config.ts tidak menemukan konfigurasi/fungsi tersebut. Kesimpulan: **prasyarat tidak teramati pada source yang diperiksa**, bukan jaminan universal aman. Maintainer tetap menyarankan upgrade; kandidat Next **16.4.1** menutup kedua advisory. [Advisory maintainer](https://github.com/vercel/next.js/security/advisories/GHSA-673q-mjm6-r5xr).

### 2. Body-parser perlu diprioritaskan walaupun severity-nya high

`body-parser 2.3.0` terpasang melalui Nest/Express. `apps/api/src/bootstrap.ts:9` mengaktifkan JSON parser dengan limit 2mb tanpa `inflate:false`; bootstrap membuat NestFactory dengan parser default. Kode adapter Nest terpasang juga memasang parser sebelum routing. Advisory menjelaskan crash proses melalui body terkompresi yang rusak; limit ukuran, DTO, autentikasi controller dan CORS bukan bukti mitigasi untuk jalur ini. **Jalur dan konfigurasi relevan teramati; crash Numora belum direproduksi.** Kandidat patched **2.4.0**; alternatif resmi `inflate:false` hanya jika kompatibilitas body terkompresi diputuskan developer. [Advisory](https://github.com/advisories/GHSA-27r3-jxmh-p828).

### 3. Audit npm tidak mencakup seluruh risiko runtime Node

Node lokal **24.14.1** melaporkan bundled Undici **7.24.4**. Versi tersebut berada dalam rentang advisory fetch/response content-encoding. Ini jalur runtime bawaan, berbeda dari npm Undici **8.11.2** milik jsdom yang hanya muncul pada graph dev. Tidak dilakukan reproduksi terhadap fetch Numora, dan endpoint berbahaya yang dapat dikendalikan penyerang belum dibuktikan. Kandidat dalam major yang disyaratkan repo adalah security release **Node 24.22.1**, yang memuat Undici **7.30.1**. Mengubah override npm Undici tidak mengganti Undici bawaan Node. [Advisory maintainer](https://github.com/nodejs/undici/security/advisories/GHSA-xjj6-f33q-929c), [rilis resmi Node](https://nodejs.org/en/blog/release/v24.22.1).

1. Review PIC untuk eksekusi workflow sudah ditutup berdasarkan persetujuan eksplisit pengguna. Anggota langsung mengikuti panduan; penugasan remediasi developer dilakukan ketika menindaklanjuti temuan dan bukan syarat memulai pengujian.

3. Critical/high yang masih relevan ditangani. Jika advisory tetap muncul tetapi sudah dimitigasi/tidak applicable, sertakan prasyarat, bukti artefak target, alasan, pemilik keputusan dan waktu review ulang. Jangan mengubah status audit mentah FAIL menjadi PASS hanya karena ada catatan risiko.

Untuk upload, gunakan suite canonical `apps/api/src/modules/content/excel-import.http.spec.ts` dan suite media/upload yang relevan. Tambahkan regresi auth/role guru/admin karena perubahan Next/Nest memengaruhi ketiganya; SIS-001 sendiri tidak membuktikan seluruh role.
6. Tiga perangkat Windows menggunakan runtime/lockfile yang sama dan lulus setup. Doctor saat ini memeriksa major Node, bukan sertifikasi patch keamanan; rekomendasi patch runtime dan artefak perlu pemeriksaan tersendiri.
