Delapan tabel, termasuk journal, attempt, versi soal, membership, dan XP, memiliki jumlah serta fingerprint yang sama sebelum dan sesudah replay kanonis. Cakupan ini sebatas data bisnis. Kepemilikan dan ACL provider diaudit terpisah. Auth, Storage, dan objek R2 berada di luar arsip.

## AI-03 — Worker, outbox, dan leaderboard

- Suite worker lulus 25 tes. Runtime lokal dengan Redis TLS memproyeksikan periode berjalan dan menguras outbox. Selama Redis berhenti, PostgreSQL menyimpan proyeksi serta event tertunda. Setelah restart dan replay, masing-masing event hanya tercatat satu kali dan satu periode aktif tetap tersedia.
- Connected IRT baseline lulus 14 skenario memakai compute fixture. Pemeriksaan mencakup cutoff, race penutupan batch, retry, adoption, dan gate pembahasan. Integrasi rilis hasil siswa tetap menunggu kontrak hasil peserta, mapping dan fallback yang disetujui Data/AI dan pemilik produk. Lihat [batas publikasi](../api/ADMIN_IRT_ANALYTICS.md#open-producer-contract-and-acceptance).
- Audit awal Development menemukan periode aktif lama dan `PVP_CONTENT_UNAVAILABLE`. Pada mode DEMO sementara, 575 keluarga soal READY lolos query bank. Filter media menolak seluruhnya karena versi lama menyimpan media kosong sebagai `{}`. Perbaikan mengakui bentuk tersebut sebagai soal teks dan tetap menolak isi media. Jumlah keluarga yang lolos menjadi 575. Mode strict tetap memerlukan metadata kesulitan akademik.
- Regresi unit gagal sebelum perbaikan. Sesudah perbaikan 18 tes PvP dan leaderboard lulus, termasuk room DEMO yang hanya bisa mencapai ambang dengan versi media kosong. Lint file berubah, typecheck API, build API dan pemeriksaan kontrak juga lulus.

- Setelah perbaikan bank, E2E lokal dua browser lulus pada tiga tingkat kesulitan. Bukti mencakup sepuluh soal per match, reconnect, Best Poin DEMO, dan XP Drill dari ledger yang sama pada leaderboard kelas dan global.
- Uji Development memakai NestJS yang dijalankan pada loopback, WebSocket, Redis TLS, PostgreSQL Development dan dua akun QA Supabase existing. Satu match DEMO mencapai `FINISHED/COMPLETED`, menerima 20 jawaban, mempertahankan room pada retry dan melanjutkan soal yang sama setelah reconnect. Akun Mandiri mendapat HTTP 403 untuk leaderboard kelas.
- Sesudah `0050`, worker dengan login runtime non-owner membangun 104 entri kelas dan dua entri PvP, termasuk peringkat dan poin kedua akun yang cocok dengan hasil pertandingan. Proyeksi pertama melewati pergantian jam sehingga pembacaan awal menampilkan stale. Pengulangan setelah pergantian jam mengembalikan board segar dan memverifikasi XP kelas/global terpisah dari Best Poin PvP. Login database sementara dicabut dan dihapus sesudah setiap smoke.
