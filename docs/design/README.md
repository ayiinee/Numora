## Core Learning inventory alignment — 2 October 2026

PRD feature inventories take precedence over old frame copy/feature assumptions. Drill requires Pretest info/Skip/result states, chapter/subchapter/level detail/history, count-up no pause, navigator/save/error/warning/confirm, success/failure result, max-three failed-only YouTube recommendations and report modals. TryOut requires Ongoing/Past cards, detail/tutorial/rules, three question formats for 35 items, countdown/auto-submit, submission success, batch/IRT waiting, immutable simulation result/explanation, session/expired/error states. No Mandiri class lock or payment UI for TryOut. Exact formula/retention/duration/scale/past-package values remain OPEN and must not be invented in UI. This documentation update does not change Figma or implementation.
