## 1. Files changed and scope

This final phase adds this report and a [tracked screenshot gallery](screenshots/redesign/README.md), then updates the [design index](README.md) and [phase ledger](UI_REDESIGN_BASELINE_2026-10-03.md). The repository CI browser limit remains unchanged.

Coverage includes:

- Google PKCE launch/callback, registration retry, identity/session failures and server role destinations, logout and direct protected-route entry.
- Student dashboard ordering/data errors, Mandiri eligibility, optional Join Class, refreshed School affiliation, class/global ranking separation and production policy gates.

- Tryout countdown/reload, lost auto-submit acknowledgement, one-attempt state, waiting IRT and released result separation.
- PvP ready/selection/lock/reconnect/server outcome and difficulty rankings; synthetic active fixtures do not enable gated production PvP.
- Feedback explicit read/error/retry/pagination, Teacher verification and owned-class/zero-vs-null progress, Admin school/token/content/report/IRT operations and development route gating.

## 7. Screenshots and running the branch

The [Git-tracked gallery](screenshots/redesign/README.md) includes Home, Bab/Subbab/Level, Drill/confirmation/result, Tryout/detail/session/waiting/released/history, PvP/create/join/waiting/battle/result/three rankings, Profile/Feedback, Teacher, Auth and every Admin workbench panel. Use **Node 24 and pnpm 12.6.0**, install dependencies with `pnpm install --frozen-lockfile`, configure the existing documented development environment, then run `pnpm dev` from the root. No new environment variable is required for the frontend redesign. Google redirect/provider configuration and API access remain the team's existing setup. Student uses `/student`, Teacher `/teacher`, Admin `/admin/schools`; protected destinations follow server identity.

The optional DEMO seed requires the explicit development opt-in documented in its README. Do not run it as a migration or against an arbitrary project. It changes no users or progress, and its content is not Curriculum-approved. For isolated browser review run `pnpm --filter @tka/web exec playwright install chromium` once, then `pnpm --filter @tka/web test:e2e`; that suite uses synthetic data and makes no cloud writes.
